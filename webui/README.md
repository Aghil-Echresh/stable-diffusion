# پنل وب فارسی Stable Diffusion

یک رابط واکنش‌گرا برای تولید تصویر با گوشی یا رایانه. **گوشی نقش مرورگر/کلاینت را دارد و مدل روی سرور اجرا می‌شود**؛ این پنل به‌تنهایی Stable Diffusion را روی گوشی نصب یا اجرا نمی‌کند.

## امکانات

- رابط راست‌چین فارسی و مناسب موبایل
- تولید متن‌به‌تصویر با مدل Diffusers-compatible
- وضعیت صف، بارگیری مدل، تولید، تکمیل و خطا
- گالری تصاویر تولیدشده و تاریخچهٔ پرامپت‌ها
- تکرار پرامپت قبلی و دانلود تصویر
- انتخاب تعداد مراحل، اندازه و seed
- API ساده برای health، jobs، history و gallery

## پیش‌نیاز سرور

- Python 3.10 یا جدیدتر
- برای تولید قابل‌استفاده، GPU انویدیا با CUDA و ترجیحاً حداقل 10 تا 12 گیگابایت VRAM؛ CPU پشتیبانی می‌شود اما بسیار کند است.
- فضای دیسک برای وزن‌های مدل (معمولاً چند گیگابایت) و تصاویر خروجی
- دسترسی به مدل انتخابی و پذیرش مجوز آن در صورت نیاز

## نصب و اجرا

از ریشهٔ مخزن:

```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell: .venv\\Scripts\\Activate.ps1
python -m pip install --upgrade pip
pip install -r webui/requirements.txt
cp webui/.env.example webui/.env
```

در صورت نیاز، متغیر `SD_MODEL_ID` را به شناسهٔ مدل Diffusers یا مسیر مدل محلی تغییر بده. سپس:

```bash
uvicorn webui.app:app --host 0.0.0.0 --port 8000
```

پنل را روی سرور با `http://127.0.0.1:8000` باز کن. برای استفاده از گوشی، گوشی و سرور باید به شبکهٔ قابل‌دسترسی مشترک متصل باشند و به‌جای localhost، IP یا دامنهٔ سرور را باز کنی. برای دسترسی عمومی، HTTPS و احراز هویت را پشت reverse proxy اضافه کن؛ این نسخه به‌صورت پیش‌فرض ورود کاربر ندارد و نباید بدون محافظت روی اینترنت عمومی منتشر شود.

## API

- `GET /api/health` — وضعیت سرور، دستگاه و بارگیری مدل
- `POST /api/generate` — ثبت درخواست؛ پاسخ شامل شناسهٔ job است
- `GET /api/jobs/{id}` — وضعیت job
- `GET /api/history` — تاریخچهٔ ذخیره‌شده
- `GET /api/gallery` — تصاویر موفق
- `DELETE /api/history` — پاک‌کردن تاریخچهٔ پرامپت‌ها (فایل تصاویر را حذف نمی‌کند)

نمونهٔ درخواست:

```json
{
  "prompt": "A quiet Persian garden at golden hour, detailed digital painting",
  "negative_prompt": "blurry, low quality",
  "steps": 25,
  "width": 512,
  "height": 512,
  "seed": 42
}
```

## نکات فنی و محدودیت‌ها

- این پنل از کد مرجع قدیمی CompVis جداست و از API پایدارتر Diffusers برای اجرای مدل استفاده می‌کند؛ فایل‌های اصلی آموزش و نمونه‌گیری مخزن دست‌نخورده می‌مانند.
- مدل به‌صورت lazy در اولین درخواست بارگیری می‌شود؛ دانلود اولیه ممکن است طول بکشد.
- این نسخه برای یک فرایند سرور و استفادهٔ شخصی طراحی شده است. برای چند کاربر هم‌زمان، صف پایدار، احراز هویت، کنترل سهمیه و مدیریت امن فایل‌ها باید اضافه شوند.
- وضعیت jobهای در حال اجرا در حافظه نگه‌داری می‌شود؛ پس از restart، وضعیت jobهای ناتمام از بین می‌رود. تاریخچه و تصاویر تکمیل‌شده روی دیسک می‌مانند.
- تست‌های خودکار را از ریشه با `python -m unittest discover -s webui/tests -v` اجرا کن. بررسی syntax: `python -m compileall -q webui`.
